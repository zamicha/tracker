# Streaks auf GitHub Pages veröffentlichen

Hochgeladen werden nur die 7 App-Dateien aus diesem Ordner. Darin ist nur der Programmcode, ohne deine Habit-Namen und ohne Einträge.

## 1. Repository anlegen
1. Auf github.com einloggen → oben rechts **+** → **New repository**.
2. Name: etwas Neutrales, z. B. `streaks`. Sichtbarkeit: **Public** (kostenloses GitHub Pages braucht das; online steht nur der leere Code).
3. **Create repository**.

## 2. Dateien hochladen
1. Im neuen Repository auf **uploading an existing file** klicken.
2. Diese 7 Dateien hineinziehen, nicht den Ordner selbst und nicht diese Anleitung:
   `index.html`, `manifest.webmanifest`, `sw.js`, `robots.txt`, `apple-touch-icon.png`, `icon-192.png`, `icon-512.png`
3. **Commit changes**.

## 3. Pages einschalten
1. **Settings** → links **Pages**.
2. Unter *Build and deployment*: Source **Deploy from a branch**, Branch **main**, Ordner **/ (root)** → **Save**.
3. Nach 1–2 Minuten steht oben der Link, z. B. `https://<dein-name>.github.io/streaks/`.

## 4. Auf dem iPhone
1. Den Link in **Safari** öffnen (nicht im privaten Modus).
2. Teilen-Symbol → **Zum Home-Bildschirm**.
3. Ab jetzt immer über das Icon auf dem Home-Bildschirm starten. So bleiben die Daten dauerhaft gespeichert.
4. Beim ersten Start deine Habits anlegen. Für ein Wochenziel wie Sport wählst du „Wochenziel“ und gibst die Teile mit Komma ein, z. B. „Ausdauer, Kraft“.

## Wichtig
- Die Einträge liegen nur auf diesem iPhone. Unter **Habits & Backup → Backup sichern** kannst du sie als Datei sichern, z. B. in der Dateien-App. Die App erinnert dich alle 14 Tage daran.
- Updates: Eine neue `index.html` im Repository hochladen. Deine Daten bleiben dabei erhalten.
